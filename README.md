# Budget Tracker CLI

Track expenses in a CSV from the terminal

## Overview
Budget Tracker CLI is a lightweight, local-first Python script designed for minimalists and terminal power users who want to log expenses without bloated apps or monthly subscriptions. It gives you direct ownership of your financial data by storing everything in a simple CSV file right on your machine.

## Use cases
- Quickly logging a morning coffee or lunch expense without opening a browser or mobile app
- Running a monthly spending summary directly in your terminal to see where your money went
- Reviewing category totals to identify and cut back on unnecessary subscriptions or dining out

## How to use
1. Download the Python script to your local machine
2. Open your terminal and run the script with your expense details
3. View your generated reports and category breakdowns instantly

## What is included
- Add expense
- Monthly report
- Category totals
